# Prototype JavaScript cũ — đã được thay thế

Đây là bản thử nghiệm client-side độc lập, dùng đường giá tổng hợp. Báo cáo audit xác định đường giá của bản này không được định giá từ đường cong lợi suất, vì vậy **không dùng nó để đại diện cho kết quả RYC hiện tại**.

Demo chính hiện tại dùng Python V3 làm lõi tính giá và cho giao diện render kết quả qua API cục bộ: [Perfect Foresight V3](../perfect-foresight/README.md).

Thư mục này được giữ như dấu vết của prototype trước; ảnh và kết quả ở đây không phải benchmark hay kết luận của nghiên cứu hiện tại.
