# Offline UI fonts

- `InterVariable.woff2`: [Inter](https://github.com/rsms/inter), downloaded from the project's `docs/font-files/InterVariable.woff2`; license in `Inter-LICENSE.txt` (SIL Open Font License 1.1).
- `JetBrainsMono-Regular.woff2`: [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono), downloaded from the project's `fonts/webfonts/JetBrainsMono-Regular.woff2`; license in `JetBrainsMono-OFL.txt` (SIL Open Font License 1.1).

These files are bundled so the local RYC workspace does not need a font CDN at runtime.
